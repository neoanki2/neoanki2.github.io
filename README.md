# NeoAnki2 documentation deployment

This repository publishes the NeoAnki2 documentation at <https://neoanki2.github.io/>.

The canonical source remains [`neoanki2/neoanki2`](https://github.com/neoanki2/neoanki2/tree/main/docs). The deployment workflow checks out that public repository, builds its Jekyll documentation with a root base URL, validates the rendered site, and deploys it to GitHub Pages. Do not edit generated documentation here.
